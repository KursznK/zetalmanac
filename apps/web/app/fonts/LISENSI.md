# Font Latin Modern

File `.otf` di folder ini adalah keluarga **Latin Modern** (LM Roman, LM Roman Caps, LM Sans,
LM Mono) karya B. Jackowski dan J. M. Nowacki (GUST e-foundry), turunan Computer Modern karya
Donald E. Knuth. Didistribusikan di bawah **GUST Font License** (https://www.gust.org.pl/projects/e-foundry/licenses).
Disalin tanpa perubahan dari distribusi TeX Live (`texmf/fonts/opentype/public/lm/`).
